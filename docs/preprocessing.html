01 · 전처리 순서

01

사용자 통합·분할

원본 train/test의 작성자·라벨 메타데이터를 합칩니다. 한 작성자에게 여러 MBTI가 있거나 EI·NS·FT·JP 축이 MBTI와 불일치하면 제외합니다. 현재 제외 작성자는 0명입니다. 작성자 이름을 정렬해 U00001 형식의 가명 ID를 만들고, MBTI로 층화한 train_test_split(random_state=42)로 사용자 단위 70:15:15 분할을 배정합니다. 원문 텍스트는 두 파일에서 배치로 읽습니다.

02

댓글 분리

원본 행의 양 끝 큰따옴표를 제거한 뒤 정확히 큰따옴표-세미콜론-큰따옴표(";") 경계를 사용해 댓글을 나눕니다. 모든 세미콜론을 분리하는 방식은 아닙니다. 이 경계는 잠정 규칙이며 의미상 댓글 경계를 전수 검증한 것은 아닙니다.

03

텍스트 정리

HTML entity 복원 → Unicode NFKC 정규화 → 줄 앞의 > 인용 제거 → 이모트 제거 → Markdown 링크의 표시 글자 보존 및 urltoken 추가 → 이메일을 emailtoken으로 치환 → URL을 urltoken으로 치환 → u/사용자·@사용자 언급을 usertoken으로 치환 → 나머지 링크·HTML 태그·일부 Markdown 기호 정리 → 연속 공백 축약 순서입니다. 인용 뒤 별도 줄에 있는 답글은 남깁니다.

04

잡음·언어 판정

빈 댓글, 미리 정의된 봇·운영자 문구, 영문 단어 정규식 기준 5단어 미만 댓글을 제외합니다. 20단어 미만은 언어 판정을 하지 않고 uncertain으로 남깁니다. 그 이상은 Lingua의 10개 언어 후보 중 최고 신뢰도가 0.70 이상일 때 english 또는 non_english로 판정하며, 그보다 낮으면 uncertain입니다. non_english만 제외합니다.

05

정확 중복 제거

정제 텍스트를 casefold한 SHA-256으로 동일 문장을 찾습니다. 같은 사용자의 중복은 한 건만 남깁니다. 여러 사용자에게 등장한 동일 텍스트는 두 번째 패스에서 처음 등장한 댓글까지 제외합니다. 유사 문장·의역 중복을 탐지하는 절차는 없습니다.

06

MBTI 누수와 결과 저장

완전한 MBTI 유형, 일부 X 유형, 구분기호를 넣은 유형, 코드에 나열된 인지기능 표기, MBTI·인지기능·에니어그램 용어 및 특정 MBTI 게시판 패턴을 high로 표시합니다. classifier_strict와 rag_train은 high가 발견된 댓글 전체를 제외합니다. introvert·thinker·neuroticism 등 weak 표현은 표시만 하며 남깁니다. 소시오닉스 개별 코드나 모든 인지기능 대소문자 변형을 포괄하지는 않습니다.

검토한 코드: mbti_full_preprocess.py. 학습 데이터에는 원래 작성자 이름 열을 저장하지 않지만, 댓글 본문에서 모든 개인정보가 제거됐다는 보장은 없습니다.

04 · 사용 전 알아둘 한계

  • 언어 판정 uncertain: 4,065,373건 (44.5%). 이 항목이 모두 비영어라는 뜻도, 영어로 검증됐다는 뜻도 아닙니다.
  • Strict에도 weak 누수 표시 댓글 14,956건이 남습니다. 유형론 관련 표현을 완전히 제거한 파일은 아닙니다.
  • 5단어 미만 보존 댓글은 0건입니다. 단어 수는 영문 정규식 기준이며 urltoken 등 치환 토큰도 셉니다.
  • 댓글이 5개를 초과하는 작성자는 10,634명이며 한 작성자의 최대 댓글 수는 69,276개입니다.
  • 동일 문자열 중복을 제거합니다. 유사 복붙, 인용 경계 오판, 문맥상 누수까지 전수 검증한 것은 아닙니다.
  • 원본 split을 합쳐 중복 텍스트를 제거했으므로 test의 존재가 코퍼스 필터링에 영향을 줍니다. 독립 배포 평가를 주장하려면 데이터 구성 정책을 따로 검토해야 합니다.
  • user_id는 가명화입니다. 작성자 자체 진술 라벨과 본문 개인정보의 정확성·완전한 비식별성을 보장하지 않습니다.

05 · 공유 파일과 읽는 방법

classifier_strict.parquet · 1,075,279,622 bytes · 1.00 GiB

Parquet 다운로드 · 데이터 Release · 행 수·SHA-256 확인

다운로드 링크는 data-v1 Release 게시 후 동작합니다. URL 읽기도 실행 환경으로 데이터를 전송하며, HTTP 구현에 따라 파일 전체를 받을 수 있습니다. 전체 텍스트를 DataFrame으로 읽으면 압축 파일보다 많은 메모리가 필요합니다.

import pandas as pd

# GitHub Release에 data-v1 데이터가 공개된 후 사용하는 주소입니다.
url = "https://github.com/seahyunjin/mbti-project/releases/download/data-v1/classifier_strict.parquet"

# 우선 필요한 열만 읽기
df = pd.read_parquet(url, columns=["user_id", "mbti", "split"])
print(df.shape)
print(pd.crosstab(df["mbti"], df["split"]))

# 텍스트를 포함한 학습용 분할을 읽으려면:

split으로 필터링할 때 val도 별도로 유지하세요. source_row_id는 각 원본 파일에서 0부터 시작하고 strict에는 source_split이 없으므로, source_row_id와 segment_id만으로 원본 댓글을 전역 식별하면 안 됩니다. 정확한 추적에는 audit의 source_split도 필요합니다.
